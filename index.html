About DOS-Core

There are several MS-DOS clones created over the years. Gathered here is a collection of free and Open Source versions including the now MIT released original MS-DOS. Many of these are still maintained and available on GitHub, Mercurial, SVN, or may only be available as ZIP archives. Historical source versions are available in many of the repositories. Where a git upstream is not available, the upstream revision control system is converted to git locally and pushed to GitHub.

The core files (kernel and shell) are all that are needed for a minimal DOS system. Pick and choose the kernel you want. Some have advanced features and others better compatibility. All have their advantages. View the source from the mirrors page or get ready to use files from builds.

What is DOS good for?

DOS still runs classic PC software, supports legacy equipment, and gives developers a small operating system to study.

  • Old hardware. Supported kernels let older PCs run DOS software. CPU requirements and FAT32 support depend on the kernel build.
  • Games. Real-mode and DOS-extender games run on bare metal the way they were written to, sound card timing and all.
  • Firmware and BIOS flashing. Plenty of vendor flash tools and diagnostics still expect to be run from a DOS boot disk or USB stick.
  • Industrial and embedded gear. CNC controllers, test rigs, lab instruments and point-of-sale boxes that have run the same DOS program for thirty years and are not about to stop.
  • Legacy business software. Accounting or database programs that source has long been lost or too expensive to upgrade.
  • Learning how an OS works. DOS source code lets you follow the boot process and see how the kernel handles files, memory, and system calls. Note though that more modern or OSes built for learning are likely to be better. But still great for hobby work or to learn about historical operating systems and how they functioned.
  • Emulator and compatibility work. Compare or run several kernels side by side, with source and history. Enjoy a taste of using computers of yore but in comfort of a modern system.
