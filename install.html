SYS A:

Making a disk bootable takes a boot sector that can find the kernel, the kernel itself, and a command shell. The SYS command (SYStem installer) writes the boot sector and copies the kernel and shell to the target disk.

Boot into FreeDOS and insert the floppy in drive A:. On a freshly formatted disk, run SYS A:. If the disk is unformatted, run FORMAT A: first.

Formatting erases the target disk. Only format a new disk or one whose contents you intend to erase. Check the drive letter before running FORMAT.

C:\>FORMAT A:
C:\>SYS A:
System transferred.

C:\>

Run SYS A: from the directory containing KERNEL.SYS and COMMAND.COM, or specify a source directory as shown below. To test the result, reboot from the floppy.

Use FORMAT A: /S as a shortcut to format the disk and install the system in one step. FreeDOS FORMAT uses SYS for /S, so make sure SYS is available.

See the FreeDOS SYS help at help.fdos.org for complete usage and options.

Using files from somewhere else

To install system files from another directory, give SYS the source directory first and the target drive second:

C:\>SYS C:\NEWKERN A:

The directory needs the kernel file and a COMMAND.COM. The FreeDOS SYS also has switches for writing only the boot sector, saving the old boot sector to a file, and installing boot sectors for kernels other than FreeDOS. See the SYS options for details.

Changing the shell

Check the shell’s kernel and CPU requirements. Copy the shell to the boot disk and tell the kernel about it with a SHELL= line in its startup configuration file.

By default, these kernels look for their own startup configuration filename first and fall back to CONFIG.SYS if it is missing:

  • FreeDOS — FDCONFIG.SYS
  • Enhanced DR-DOS (SvarDOS and ecm) — DCONFIG.SYS
  • lDOS — LDOS.INI
  • RxDOS — RXCONFIG.SYS
REM FreeCOM
SHELL=A:\COMMAND.COM A:\ /E:1024 /P

REM 4DOS
SHELL=A:\4DOS.COM A:\ /P

/P makes it the permanent shell and runs AUTOEXEC.BAT. /E sets the environment size. Each shell has its own extras, so check its documentation.

No floppy drive?

Most people try these out in an emulator first, and that is the recommended way if you are new or don't have an old PC available. QEMU, 86Box, PCem, VirtualBox and DOSBox-X can all boot a raw 1.44 MB floppy image. Make a blank image, format it and SYS it from inside a running DOS, then boot from it:

$ qemu-system-i386 -fda floppy.img -boot a

On real hardware without a floppy, a USB stick set to floppy or hard disk emulation in the BIOS behaves the same way. Write the image to it with whatever raw disk writer you trust.

Before you touch drive C:

  • Back up first. SYS C: rewrites the boot sector of that partition.
  • If another OS boots from that disk, save its boot sector before you start. FreeDOS SYS can write the old sector to a file for you.
  • Make sure the partition is marked active, or use a boot manager that can chain to it.
  • Keep a boot floppy or image handy that you know works.
