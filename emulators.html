Emulators

Boot a DOS disk image, reproduce an older PC, or run a DOS application.

  • Open-source virtualization and PC emulation
  • Browser emulators
  • DOS applications and games
  • Vendor virtualization

See Builds for DOS downloads and Install for help preparing a boot disk.

Open-source virtualization and PC emulation

Use a full-system emulator to reproduce a classic PC or simulate particular PC hardware.

ProjectWhat it runs
QEMUFull-system emulation for booting disk images, with optional hardware acceleration on supported hosts.
KVMLinux kernel virtualization support. QEMU can use KVM to accelerate compatible guests.
86BoxEmulates period PC motherboards, video cards, and sound hardware.
PCemEmulates a range of IBM PCs and compatibles with configurable period hardware.
BochsPortable x86 PC emulator with a CPU debugger.
MartyPCRust emulator focused on cycle-accurate IBM PC, XT, PCjr, and Tandy emulation.
XTulatorA portable emulator for XT-era PCs with 8086 and 80186 instruction support.
8086tinyA compact 8086 PC emulator.
Fake86 ReduxA continuation of the Fake86 early x86 PC emulator.

Browser emulators

Emulators that run in the browser using JavaScript/WebAssembly. Refer to the project’s own site or repository for more information.

ProjectWhat it runs
PCjs MachinesJeff Parsons’s JavaScript simulations of the original IBM PC, XT, AT, and other machines, with runnable demos.
JSLinuxFabrice Bellard’s browser virtual machines, with ready-to-run guest images.
v86Browser x86 emulation with a WebAssembly CPU translator and an option to load your own disk images.
js-dosBrowser runtime for DOSBox-based packages, with a JavaScript API for embedding DOS programs.
e486-webA JavaScript 486 PC emulator with configurable motherboard and expansion devices.
PCE for the browserA WebAssembly port of PCE that includes IBM PC emulation.
jemul8A JavaScript x86 emulator for web browsers and Node.js.

DOS applications and games

These projects are designed for running DOS programs, so provide their own kernel API but many can also run other kernels.

ProjectWhat it runs
DOSBoxThe original DOSBox project, focused on running DOS games.
DOSBox-XA DOSBox fork that also supports booting DOS from disk images.
DOSBox StagingA modern continuation of DOSBox with updated audio, video, and usability features.
DOSBox PureA DOSBox-based core for RetroArch and other Libretro frontends.
DOSEMU2Runs DOS programs on Linux.

Vendor virtualization

For DOS guests, check for legacy BIOS boot and compatible virtual hardware. Links for discontinued Microsoft products provide historical descriptions.

ProjectWhat it runs
Oracle VirtualBoxDesktop virtual machines with BIOS boot and virtual disk images.
VMware Workstation and FusionVMware’s desktop virtual machine products. Workstation runs on Windows and Linux, and Fusion runs on macOS. For DOS, use an x86 guest on an x86 host.
Microsoft Virtual PCHistorical x86 PC emulation for older Windows NT based systems and PowerPC Macs.
Microsoft Virtual Server 2005 R2Microsoft’s historical server virtualization product.
Microsoft Hyper-VMicrosoft’s Windows hypervisor. Generation 1 VMs provide legacy BIOS boot.
Parallels Desktop for MacCommercial Mac virtualization. The x86 emulator on Apple silicon requires UEFI, so it cannot directly boot a classic DOS disk.
SunPCiSun Microsystems hardware and software for running PC guests on SPARC workstations under Solaris. The original SunPCi shipped with Caldera OpenDOS.
Insignia SoftPC and SoftWindowsHistorical PC emulation for Unix workstations and Macs. SoftPC ran MS-DOS, and SoftWindows targeted Windows applications.
Locus DOS MergeRan DOS and later Windows 3.1 in a virtual machine on Unix systems such as SCO UNIX.
RealPCPentium PC emulation for PowerPC Macs. It shipped with MS-DOS 6.22 and emulated Sound Blaster audio.
